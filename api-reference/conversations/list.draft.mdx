</Note>

Devuelve las conversaciones de la organización, de la actividad más reciente a la más antigua. Cada conversación pertenece a un lead y agrupa todo el intercambio con esa persona. Al filtrar por `lead_id` se obtienen los hilos de un contacto puntual; al filtrar por `status` se monitorean los hilos abiertos o los que ya están en manos de un vendedor.

Los objetos de esta lista no incluyen el arreglo `messages`. Para el hilo completo se usa [Obtener conversación](/api-reference/conversations/get).

## Endpoint

```text
GET https://platform-api.deltalead.ai/v1/conversations
```

## Parámetros de consulta

<ParamField query="limit" type="integer" default="20">
  Cantidad máxima de conversaciones que se devuelven por página. Acepta valores entre `1` y `100`.
</ParamField>

<ParamField query="cursor" type="string">
  Cursor de paginación opaco, tomado del campo `next_cursor` de la respuesta anterior. Si se omite, la lectura empieza por la primera página. El cursor no se parsea ni se construye a mano.
</ParamField>

<ParamField query="lead_id" type="string">
  Limita las conversaciones a un lead determinado. Se pasa un ID de lead como `lead_abc123`.
</ParamField>

<ParamField query="status" type="string">
  Filtra por estado de la conversación. Valores aceptados: `open`, `handed_off`, `resolved`.
</ParamField>

<ParamField query="assignee" type="string">
  Limita las conversaciones a las asignadas a una persona determinada, por su ID de usuario.
</ParamField>

## Solicitud de ejemplo

```bash cURL
curl 'https://platform-api.deltalead.ai/v1/conversations?lead_id=lead_abc123&status=open' \
  -H "Authorization: Bearer dl_live_..."
```

## Respuesta

Una solicitud correcta devuelve `200 OK` con un arreglo `data` de conversaciones y los campos de paginación `next_cursor` y `has_more` en el nivel raíz.

```json 200 OK
{
  "data": [
    {
      "id": "conv_xyz789",
      "organization_id": "org_xyz789",
      "lead_id": "lead_abc123",
      "status": "open",
      "assignee": null,
      "unread_count": 2,
      "last_inbound_at": "2024-03-11T09:04:58Z",
      "last_message_at": "2024-03-11T09:05:33Z"
    },
    {
      "id": "conv_mno321",
      "organization_id": "org_xyz789",
      "lead_id": "lead_def456",
      "status": "handed_off",
      "assignee": "user_xyz789",

    }

  "has_more": false
}
```

### Campos de la respuesta

<ResponseField name="data" type="array">
  Arreglo de conversaciones que coinciden con los filtros aplicados.
</ResponseField>

<ResponseField name="data[].id" type="string">
  Identificador único de la conversación, con el prefijo `conv_`.
</ResponseField>

<ResponseField name="data[].organization_id" type="string">
  ID de la organización a la que pertenece la conversación.
</ResponseField>

<ResponseField name="data[].lead_id" type="string">
  ID del lead al que pertenece la conversación. Los datos de contacto se obtienen desde [Obtener lead](/api-reference/leads/get), donde viven dentro de `contact`.
</ResponseField>

<ResponseField name="data[].status" type="string">
  Estado actual de la conversación. Uno de:
  - `open` — la atiende el agente de IA
  - `handed_off` — derivada a una persona, que es quien responde
  - `resolved` — cerrada, no se esperan más mensajes
</ResponseField>

<ResponseField name="data[].assignee" type="string | null">
  ID de la persona a cargo de la conversación. Es `null` mientras la conversación la atiende el agente de IA.
</ResponseField>

<ResponseField name="data[].unread_count" type="integer">
  Cantidad de mensajes entrantes sin leer en el Inbox unificado.
</ResponseField>

<ResponseField name="data[].last_inbound_at" type="string | null">
  Marca de tiempo ISO 8601 del último mensaje enviado por el lead. Es `null` si el lead todavía no respondió.
</ResponseField>

<ResponseField name="data[].last_message_at" type="string">
  Marca de tiempo ISO 8601 del mensaje más reciente de la conversación, en cualquier dirección.
</ResponseField>

<ResponseField name="next_cursor" type="string | null">
  Este valor se pasa como `cursor` para obtener la página siguiente. Es `null` cuando `has_more` es `false`.
</ResponseField>

<ResponseField name="has_more" type="boolean">
  `true` si existen páginas adicionales.
</ResponseField>
