<Note>
  La API REST está en acceso anticipado y se habilita por cuenta a pedido. Las claves de API no se emiten todavía desde el panel. Para solicitar acceso, contactar al ejecutivo de cuenta.
</Note>

Devuelve una conversación puntual a partir de su identificador, con el hilo completo de mensajes. Sirve para incrustar el historial dentro de los registros del CRM, auditar las respuestas del agente de IA o mostrarle el contexto completo a un vendedor antes de que tome el relevo.

La conversación referencia al lead por `lead_id`. Los datos de contacto no viajan acá: se obtienen desde [Obtener lead](/api-reference/leads/get), donde viven dentro del objeto `contact`.

## Endpoint

```text
GET https://platform-api.deltalead.ai/v1/conversations/{id}
```

## Parámetros de ruta

<ParamField path="id" type="string" required>
  Identificador único de la conversación que se quiere recuperar, por ejemplo `conv_xyz789`. Los ID de conversación se obtienen desde el endpoint [Listar conversaciones](/api-reference/conversations/list) o desde los payloads de webhook.
</ParamField>

## Solicitud de ejemplo

```bash cURL
curl https://platform-api.deltalead.ai/v1/conversations/conv_xyz789 \
  -H "Authorization: Bearer dl_live_..."
```

### Campos de la respuesta

<ResponseField name="id" type="string">
  Identificador único de la conversación, con el prefijo `conv_`.
</ResponseField>

<ResponseField name="organization_id" type="string">
  ID de la organización a la que pertenece la conversación.
</ResponseField>

<ResponseField name="lead_id" type="string">
  ID del lead al que pertenece la conversación.
</ResponseField>

<ResponseField name="status" type="string">
  Estado actual: `open` (la atiende el agente de IA), `handed_off` (derivada a una persona) o `resolved` (cerrada).
</ResponseField>

<ResponseField name="assignee" type="string | null">
  ID de la persona a cargo de la conversación. Es `null` mientras la atiende el agente de IA.
</ResponseField>

<ResponseField name="unread_count" type="integer">
  Cantidad de mensajes entrantes sin leer en el Inbox unificado.
</ResponseField>

<ResponseField name="last_inbound_at" type="string | null">
  Marca de tiempo ISO 8601 del último mensaje enviado por el lead.
</ResponseField>

<ResponseField name="last_message_at" type="string">
  Marca de tiempo ISO 8601 del mensaje más reciente, en cualquier dirección.
</ResponseField>

<ResponseField name="messages" type="array">
  Arreglo ordenado de mensajes, del más antiguo al más reciente.

  <Expandable title="Campos del objeto de mensaje">
    <ResponseField name="id" type="string">
      Identificador único del mensaje, con el prefijo `msg_`.
    </ResponseField>
    <ResponseField name="conversation_id" type="string">
      ID de la conversación a la que pertenece el mensaje.
    </ResponseField>
    <ResponseField name="direction" type="string">
      `inbound` para los mensajes enviados por el lead; `outbound` para los que envía DeltaLead, sea el agente de IA o una persona.
    </ResponseField>
    <ResponseField name="body" type="string">
      Cuerpo de texto del mensaje. Queda vacío cuando el mensaje solo tiene adjuntos: el contenido está entonces en `media`.
    </ResponseField>
    <ResponseField name="type" type="string">
      Tipo de mensaje. Uno de `text`, `audio`, `image`, `document`.
    </ResponseField>
    <ResponseField name="media" type="array">
      Archivos adjuntos al mensaje. Es un arreglo vacío en los mensajes de texto.

      <Expandable title="Campos del objeto de media">
        <ResponseField name="id" type="string">
          Identificador único del archivo.
        </ResponseField>
        <ResponseField name="type" type="string">
          Tipo del archivo. Uno de `audio`, `image`, `document`.
        </ResponseField>
        <ResponseField name="url" type="string">
          URL de descarga del archivo. Requiere la misma clave de API que el resto de la API.
        </ResponseField>
        <ResponseField name="mime_type" type="string">
          Tipo MIME del archivo, por ejemplo `audio/ogg`.
        </ResponseField>
        <ResponseField name="transcription" type="string | null">
          Transcripción del audio, cuando el archivo es de tipo `audio` y la transcripción ya está lista. Es `null` en el resto de los casos. La transcripción viaja siempre acá, nunca en un campo aparte de la conversación.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="sender" type="string">
      Quién originó el mensaje. Uno de `lead`, `ai_agent`, `human`.
    </ResponseField>
    <ResponseField name="ai_agent_id" type="string | null">
      ID del agente de IA que generó el mensaje. Es `null` cuando `sender` no es `ai_agent`.
    </ResponseField>
    <ResponseField name="ai_agent_name" type="string | null">
      Nombre del agente de IA al momento de enviar el mensaje. Se guarda junto al mensaje para que el historial no cambie si después se renombra el agente.
    </ResponseField>
    <ResponseField name="status" type="string">
      Estado de entrega del mensaje. Uno de `queued`, `sent`, `delivered`, `failed`.
    </ResponseField>
    <ResponseField name="error_code" type="string | null">
      Identificador del motivo de falla, en `snake_case`. Solo viene con valor cuando `status` es `failed`.
    </ResponseField>
    <ResponseField name="received_at" type="string | null">
      Marca de tiempo ISO 8601 del momento en que el canal entregó el mensaje a DeltaLead. Es `null` en los mensajes salientes.
    </ResponseField>
    <ResponseField name="created_at" type="string">
      Marca de tiempo ISO 8601 de la creación del mensaje.
    </ResponseField>
    <ResponseField name="updated_at" type="string">
      Marca de tiempo ISO 8601 del último cambio en el mensaje, por ejemplo al pasar de `sent` a `delivered` o al completarse una transcripción.
    </ResponseField>
  </Expandable>
</ResponseField>
