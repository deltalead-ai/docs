</Note>

Esta página es la referencia definitiva de cada evento de webhook que DeltaLead puede entregar a un endpoint. Los eventos se agrupan por dominio: ciclo de vida del lead, actividad de conversación, citas y derivaciones a una persona. De cada evento se documenta la condición que lo dispara y un payload de ejemplo completo, para saber con exactitud qué esperar en el manejador.

<Note>
  Conviene suscribirse únicamente a los eventos que la integración realmente necesita. Descartar los tipos de evento irrelevantes reduce las solicitudes POST innecesarias hacia el servidor y mantiene acotada la lógica del manejador.
</Note>

## Eventos del ciclo de vida del lead

<Accordion title="lead.created — Ingresa un lead nuevo a DeltaLead">
  Se dispara en el momento en que llega un lead nuevo a DeltaLead desde cualquier canal conectado: WhatsApp, MercadoLibre, Typeform, el Custom Webhook, email o carga manual. Al crearse, el score del lead es `0`; la calificación ocurre de forma asincrónica y dispara `lead.qualified` una vez completada.

  ```json Example payload
  {
    "event": "lead.created",
    "timestamp": "2024-11-07T10:00:00Z",
    "organization_id": "org_xyz789",
    "data": {
      "id": "lead_abc123",
      "status": "new",
      "score": 0,
      "source": "landing-page",
      "contact": {
        "first_name": "Carlos",
        "last_name": "Rodríguez",
        "email": "carlos.rodriguez@example.com",
        "phone": "+5491144441234"
      },
      "channels": ["whatsapp"],
      "interested_vehicles": ["veh_9f3c21"],
      "created_at": "2024-11-07T10:00:00Z"
    }
  }
  ```
</Accordion>

<Accordion title="lead.qualified — La IA completa la calificación del lead">
  Se dispara cuando el agente de IA termina su conversación de calificación y asigna un score de intención de compra. El campo `score` va de `0` a `100`. El resumen que produce la calificación se refleja en `ai_summary_status`, que pasa a `completed` cuando el Resumen de IA queda disponible en el lead.

  ```json Example payload
  {
    "event": "lead.qualified",
    "timestamp": "2024-11-07T10:07:30Z",
    "organization_id": "org_xyz789",
    "data": {
      "id": "lead_abc123",
      "status": "qualified",
      "score": 87,
      "contact": {
        "first_name": "Carlos",
        "last_name": "Rodríguez",
        "email": "carlos.rodriguez@example.com",
        "phone": "+5491144441234"
      },
      "channels": ["whatsapp"],
      "interested_vehicles": ["veh_9f3c21"],
      "ai_summary_status": "completed"
    }
  }
  ```
</Accordion>

<Accordion title="lead.updated — Cambia el estado, el score o la asignación del lead">
  Se dispara cada vez que se modifica un registro de lead después de su creación. Entre los disparadores habituales están un cambio manual de estado hecho por un vendedor, una revisión del score tras una conversación de seguimiento o una actualización de los vehículos de interés.

  ```json Example payload
  {
    "event": "lead.updated",
    "timestamp": "2024-11-07T11:00:00Z",
    "organization_id": "org_xyz789",
    "data": {
      "id": "lead_abc123",
      "status": "contacted",
      "score": 91,
      "contact": {
        "first_name": "Carlos",
        "last_name": "Rodríguez",
        "email": "carlos.rodriguez@example.com",
        "phone": "+5491144441234"
      },
      "channels": ["whatsapp"],
      "interested_vehicles": ["veh_9f3c21"],
      "updated_at": "2024-11-07T11:00:00Z"
    }
  }
  ```
</Accordion>

<Accordion title="lead.assigned — El lead se asigna a un vendedor">
  Se dispara cuando un lead calificado se asigna a un integrante concreto del equipo de ventas, ya sea de forma automática por las reglas de enrutamiento de DeltaLead o de forma manual por un responsable. Este evento sirve para avisarle al vendedor asignado desde sistemas propios.

  ```json Example payload
  {
    "event": "lead.assigned",
    "timestamp": "2024-11-07T11:05:00Z",
    "organization_id": "org_xyz789",
    "data": {
      "id": "lead_abc123",
      "status": "qualified",
      "score": 91,
      "contact": {
        "first_name": "Carlos",
        "last_name": "Rodríguez",
        "email": "carlos.rodriguez@example.com",
        "phone": "+5491144441234"
      },
      "assigned_to": {
        "id": "user_seller001",
        "name": "Laura Méndez",
        "email": "laura.mendez@concesionaria.com"
      },
      "channels": ["whatsapp"],
      "interested_vehicles": ["veh_9f3c21"]
    }
  }
  ```
</Accordion>

## Eventos de conversación

<Accordion title="conversation.started — Comienza una conversación nueva">
  Se dispara cuando un lead inicia una conversación nueva en cualquier canal. Un mismo lead puede tener varias conversaciones a lo largo del tiempo; cada una dispara su propio evento `conversation.started`.

  ```json Example payload
  {
    "event": "conversation.started",
    "timestamp": "2024-11-07T10:00:05Z",
    "organization_id": "org_xyz789",
    "data": {
      "id": "conv_111aaa",
      "lead_id": "lead_abc123",
      "status": "open",
      "assignee": null,
      "unread_count": 1,
      "last_inbound_at": "2024-11-07T10:00:05Z"
    }
  }
  ```
</Accordion>

<Accordion title="message.received — Llega un mensaje entrante">
  Se dispara cada vez que se recibe un mensaje entrante del lead durante una conversación activa. Suscribirse a este evento permite replicar el historial de conversación en un CRM o data warehouse propio en tiempo real. El cuerpo del mensaje viaja en `body`; los adjuntos y la transcripción de audio, cuando existen, viajan en `media`.

  ```json Example payload
  {
    "event": "message.received",
    "timestamp": "2024-11-07T10:01:20Z",
    "organization_id": "org_xyz789",
    "data": {
      "conversation_id": "conv_111aaa",
      "lead_id": "lead_abc123",
      "message": {
        "id": "msg_999zzz",
        "direction": "inbound",
        "body": "¿Tienen la Hilux SRX en stock?",
        "type": "text",
        "media": [],
        "received_at": "2024-11-07T10:01:20Z"
      }
    }
  }
  ```
</Accordion>

## Eventos de citas

<Accordion title="appointment.scheduled — La IA agenda un test drive o una visita al showroom">
  Se dispara cuando un agente de IA logra agendar una cita con un lead, por lo general un test drive o una visita al showroom. Este evento sirve para sumar la cita al sistema de calendario, avisarle al vendedor responsable o preparar el vehículo.

  ```json Example payload
  {
    "event": "appointment.scheduled",
    "timestamp": "2024-11-07T10:12:00Z",
    "organization_id": "org_xyz789",
    "data": {
      "lead_id": "lead_abc123",
      "conversation_id": "conv_111aaa",
      "appointment_type": "test_drive",
      "scheduled_at": "2024-11-09T11:00:00Z"
    }
  }
  ```
</Accordion>

## Eventos de derivación

<Accordion title="escalation.created — La IA transfiere la conversación a una persona">
  Se dispara cuando un agente de IA determina que la conversación requiere intervención humana y la deriva. Ocurre al cumplirse alguna de las reglas de negocio configuradas en el agente, por ejemplo un lead que pide negociar el precio o consultar las condiciones de financiación. El vendedor que la recibe obtiene el contexto completo de la conversación.

  ```json Example payload
  {
    "event": "escalation.created",
    "timestamp": "2024-11-07T10:15:00Z",
    "organization_id": "org_xyz789",
    "data": {
      "conversation_id": "conv_111aaa",
      "lead_id": "lead_abc123",
      "ai_agent_id": "agent_abc123",
      "ai_agent_name": "Martín de Ventas",
      "reason": "financing",
      "assigned_to": {
        "id": "user_seller001",
        "name": "Laura Méndez",
        "email": "laura.mendez@concesionaria.com"
      },
      "escalated_at": "2024-11-07T10:15:00Z"
    }
  }
  ```
</Accordion>
