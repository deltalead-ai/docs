<Note>
  La API REST está en acceso anticipado y se habilita por cuenta a pedido. Las claves de API no se emiten todavía desde el panel. Para solicitar acceso, contactar al ejecutivo de cuenta.
</Note>

Devuelve una lista paginada de los agentes de IA configurados en la organización. Cada registro trae la configuración completa que gobierna cómo conversa el agente: idioma, tono, extensión de los mensajes, número asignado y las reglas de negocio y de calificación con las que trabaja.

## Endpoint

```http
GET https://platform-api.deltalead.ai/v1/agents
```

## Parámetros de consulta

<ParamField query="limit" type="integer" default="20">
  Cantidad máxima de agentes de IA que se devuelven por página. Acepta valores entre `1` y `100`.
</ParamField>

<ParamField query="cursor" type="string">
  Cursor de paginación opaco, tomado del campo `next_cursor` de la respuesta anterior. Si se omite, la lectura empieza por el comienzo de la lista. El cursor no se parsea ni se construye a mano.
</ParamField>

## Solicitud de ejemplo

```bash cURL
curl https://platform-api.deltalead.ai/v1/agents \
  -H "Authorization: Bearer dl_live_..."
```

## Respuesta

### Campos de la respuesta

<ResponseField name="data" type="array">
  Arreglo de agentes de IA de la organización.

  <Expandable title="Campos del agente de IA">
    <ResponseField name="id" type="string">
      Identificador único del agente de IA, por ejemplo `agent_abc123`.
    </ResponseField>
    <ResponseField name="organization_id" type="string">
      ID de la organización a la que pertenece el agente de IA.
    </ResponseField>
    <ResponseField name="name" type="string">
      Nombre con el que el agente de IA se presenta ante el lead.
    </ResponseField>
    <ResponseField name="type" type="string">
      Tipo de agente, por ejemplo `sales` o `support`. Determina el playbook que sigue y se define durante el onboarding.
    </ResponseField>
    <ResponseField name="language" type="string">
      Clave de locale con la que conversa el agente de IA: `es_AR`, `es_MX`, `es_CR`, `es_CO`, `pt_BR` o `en_US`.
    </ResponseField>
    <ResponseField name="tone_of_voice" type="string">
      Tono conversacional: `formal`, `friendly` o `professional`.
    </ResponseField>
    <ResponseField name="text_size" type="string">
      Extensión de los mensajes que redacta el agente de IA: `short`, `medium` o `long`.
    </ResponseField>
    <ResponseField name="assigned_phone_value" type="string | null">
      Número de teléfono en formato E.164 desde el que conversa el agente de IA. Es `null` si todavía no tiene número asignado.
    </ResponseField>
    <ResponseField name="version" type="integer">
      Número de versión de la configuración. Se incrementa con cada actualización del agente de IA.
    </ResponseField>
    <ResponseField name="business_rules" type="string">
      Reglas de negocio con las que responde el agente de IA: límites de descuento, condiciones de financiación, plazos de entrega.
    </ResponseField>
    <ResponseField name="lead_qualification_rules" type="string">
      Reglas que definen cuándo el agente de IA considera calificado a un lead y qué información necesita reunir antes.
    </ResponseField>
    <ResponseField name="created_at" type="string">
      Marca de tiempo ISO 8601 de la creación del agente de IA.
    </ResponseField>
    <ResponseField name="updated_at" type="string">
      Marca de tiempo ISO 8601 de la actualización más reciente.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="next_cursor" type="string | null">
  Este valor se pasa como `cursor` para obtener la página siguiente. Es `null` cuando `has_more` es `false`.
</ResponseField>

<ResponseField name="has_more" type="boolean">
  `true` si existen páginas adicionales.
</ResponseField>

<Note>
  Este endpoint lista agentes de IA, no vendedores. Los vendedores son personas del concesionario, con nombre, apodo y descripción, y son a quienes se asigna una conversación derivada mediante el campo `assignee`. Los dos recursos son distintos y no comparten identificadores.
</Note>
