---
title: "PATCH /v1/agents/{id} — actualizar un agente de IA"
sidebarTitle: "Actualizar agente"
description: "PATCH /v1/agents/{id} actualiza parcialmente el idioma, el tono, la extensión de los mensajes y las reglas de negocio y de calificación de un agente de IA."
---

<Note>
  La API REST está en acceso anticipado y se habilita por cuenta a pedido. Las claves de API no se emiten todavía desde el panel. Para solicitar acceso, contactar al ejecutivo de cuenta.
</Note>

Actualiza la configuración de un agente de IA existente sin reemplazar el registro completo. Se envían únicamente los campos que se quieren cambiar: DeltaLead aplica una actualización parcial y deja intacto todo campo no especificado. Sirve para ajustar cómo conversa el agente de IA con el tiempo, adaptarlo a un mercado nuevo o incorporar una regla comercial que antes no existía.

## Endpoint

```http
PATCH https://platform-api.deltalead.ai/v1/agents/{id}
```

## Parámetros de ruta

<ParamField path="id" type="string" required>
  Identificador único del agente de IA que se quiere actualizar, por ejemplo `agent_abc123`.
</ParamField>

## Cuerpo de la solicitud

Todos los campos son opcionales. Se incluyen solo los que se quieren cambiar.

<ParamField body="language" type="string">
  Clave de locale con la que conversa el agente de IA. Valores aceptados: `es_AR`, `es_MX`, `es_CR`, `es_CO`, `pt_BR`, `en_US`.
</ParamField>

<ParamField body="tone_of_voice" type="string">
  Tono conversacional. Valores aceptados: `formal`, `friendly`, `professional`.
</ParamField>

<ParamField body="text_size" type="string">
  Extensión de los mensajes que redacta el agente de IA. Valores aceptados: `short`, `medium`, `long`.
</ParamField>

<ParamField body="business_rules" type="string">
  Reglas de negocio del agente de IA: límites de descuento, condiciones de financiación, plazos de entrega. Reemplaza el texto completo, no lo agrega al existente.
</ParamField>

<ParamField body="lead_qualification_rules" type="string">
  Reglas de calificación del agente de IA. Reemplaza el texto completo, no lo agrega al existente.
</ParamField>

<Note>
  `name`, `type` y `assigned_phone_value` no se editan por API: se definen al crear el agente de IA y al asignarle un número desde el panel. `version`, `created_at` y `updated_at` los mantiene la plataforma.
</Note>

## Solicitud de ejemplo

La siguiente solicitud adapta el agente de IA a México, lo pasa a un tono profesional y acorta sus mensajes.

```bash cURL
curl -X PATCH https://platform-api.deltalead.ai/v1/agents/agent_abc123 \
  -H "Authorization: Bearer dl_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "language": "es_MX",
    "tone_of_voice": "professional",
    "text_size": "short"
  }'
```

## Respuesta

Una solicitud correcta devuelve `200 OK` con el objeto completo del agente de IA ya actualizado y el campo `version` incrementado.

```json 200 OK
{
  "id": "agent_abc123",
  "organization_id": "org_xyz789",
  "name": "Martín de Ventas",
  "type": "sales",
  "language": "es_MX",
  "tone_of_voice": "professional",
  "text_size": "short",
  "assigned_phone_value": "+5491123456789",
  "version": 8,
  "business_rules": "No ofrecer descuentos mayores al 5% sin aprobación. Financiación hasta 60 cuotas.",
  "lead_qualification_rules": "Calificar cuando el lead confirma modelo, presupuesto y plazo de compra.",
  "created_at": "2024-01-15T10:00:00Z",
  "updated_at": "2024-11-07T17:45:00Z"
}
```

## Respuestas de error

Cuando el ID no corresponde a ningún agente de IA de la organización, la API devuelve `404 Not Found`.

```json 404 Not Found
{
  "status": "error",
  "detail": "agent_not_found"
}
```

<Warning>
  Los cambios rigen para los mensajes que el agente de IA genera a partir de ese momento, también en las conversaciones ya abiertas. Un cambio de `language` o de `business_rules` en pleno horario comercial se nota en la respuesta siguiente: conviene revisar antes qué conversaciones están activas.
</Warning>
