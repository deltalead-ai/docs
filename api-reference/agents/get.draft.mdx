Devuelve la configuración completa de un agente de IA a partir de su ID: el idioma en el que conversa, su tono, la extensión de los mensajes que redacta, el número desde el que escribe y las reglas de negocio y de calificación que sigue.

Un agente de IA no es un vendedor. Los vendedores son personas del concesionario y reciben las conversaciones derivadas; los agentes de IA son los que conversan de forma automática y son el recurso que describe esta sección.

## Endpoint

```http
GET https://platform-api.deltalead.ai/v1/agents/{id}
```

## Parámetros de ruta

<ParamField path="id" type="string" required>
  Identificador único del agente de IA que se quiere recuperar, por ejemplo `agent_abc123`.
</ParamField>

## Solicitud de ejemplo

```bash cURL
curl https://platform-api.deltalead.ai/v1/agents/agent_abc123 \
  -H "Authorization: Bearer dl_live_..."
```

## Respuesta

Una solicitud correcta devuelve `200 OK` con el objeto completo del agente de IA.

```json 200 OK
{
  "id": "agent_abc123",
  "organization_id": "org_xyz789",
  "name": "Martín de Ventas",
  "type": "sales",
  "language": "es_AR",
  "tone_of_voice": "friendly",
  "text_size": "short",
  "assigned_phone_value": "+5491123456789",
  "version": 7,
  "business_rules": "No ofrecer descuentos mayores al 5% sin aprobación. Financiación hasta 60 cuotas.",
  "lead_qualification_rules": "Calificar cuando el lead confirma modelo, presupuesto y plazo de compra.",
  "created_at": "2024-01-15T10:00:00Z",
  "updated_at": "2024-10-01T08:30:00Z"
}
```

### Campos de la respuesta

<ResponseField name="id" type="string">
  Identificador único del agente de IA.
</ResponseField>

<ResponseField name="organization_id" type="string">
  ID de la organización a la que pertenece el agente de IA.
</ResponseField>

<ResponseField name="name" type="string">
  Nombre con el que el agente de IA se presenta ante el lead.
</ResponseField>

<ResponseField name="type" type="string">
  Tipo de agente, por ejemplo `sales` o `support`. Determina el playbook que sigue y se define durante el onboarding.
</ResponseField>

<ResponseField name="language" type="string">
  Clave de locale con la que conversa el agente de IA: `es_AR`, `es_MX`, `es_CR`, `es_CO`, `pt_BR` o `en_US`.
</ResponseField>

<ResponseField name="tone_of_voice" type="string">
  Tono conversacional: `formal`, `friendly` o `professional`.
</ResponseField>

<ResponseField name="text_size" type="string">
  Extensión de los mensajes que redacta el agente de IA: `short`, `medium` o `long`.
</ResponseField>

<ResponseField name="assigned_phone_value" type="string | null">
  Número de teléfono en formato E.164 desde el que conversa el agente de IA. Es `null` si todavía no tiene número asignado.
</ResponseField>

<ResponseField name="version" type="integer">
  Número de versión de la configuración. Se incrementa con cada actualización.
</ResponseField>

<ResponseField name="business_rules" type="string">
  Reglas de negocio con las que responde el agente de IA: límites de descuento, condiciones de financiación, plazos de entrega. Es el texto que se edita desde [Actualizar agente](/api-reference/agents/update).
</ResponseField>

<ResponseField name="lead_qualification_rules" type="string">
  Reglas que definen cuándo el agente de IA considera calificado a un lead y qué información necesita reunir antes.
</ResponseField>

<ResponseField name="created_at" type="string">
  Marca de tiempo ISO 8601 de la creación del agente de IA.
</ResponseField>

<ResponseField name="updated_at" type="string">
  Marca de tiempo ISO 8601 de la actualización más reciente.
</ResponseField>

## Respuestas de error

Cuando el ID no corresponde a ningún agente de IA de la organización, la API devuelve `404 Not Found`.

```json 404 Not Found
{
  "status": "error",
  "detail": "agent_not_found"
}
```
