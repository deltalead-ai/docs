</Note>

Este endpoint devuelve los leads de la organización en una respuesta paginada por cursor. Los parámetros de consulta acotan el resultado por estado, canal, rango de score, vehículo del catálogo, texto libre o fecha de creación, para aislar el segmento del pipeline que necesita la integración.

## Endpoint

```text
GET https://platform-api.deltalead.ai/v1/leads
```

## Parámetros de consulta

<ParamField query="limit" type="integer" default="20">
  Cantidad máxima de leads por página. Entero entre `1` y `100`.
</ParamField>

<ParamField query="cursor" type="string">
  Cursor de paginación devuelto en `next_cursor` por la respuesta anterior. Se omite para empezar por la primera página. El valor es opaco: no se parsea ni se construye.
</ParamField>

<ParamField query="status" type="string">
  Filtra por estado actual del lead. Valores aceptados: `new`, `contacted`, `qualified`, `appointment`, `proposal`, `incubating`, `won`, `lost`.
</ParamField>

<ParamField query="channel" type="string">
  Devuelve los leads que acumularon este canal. Valores aceptados: `whatsapp`, `mercadolibre`, `typeform`, `custom`, `manual`, `email`.
</ParamField>

<ParamField query="score_min" type="integer">
  Devuelve solo los leads con un score mayor o igual a este valor. Rango: `0`–`100`.
</ParamField>

<ParamField query="score_max" type="integer">
  Devuelve solo los leads con un score menor o igual a este valor. Rango: `0`–`100`.
</ParamField>

<ParamField query="interested_vehicle_ids" type="string">
  Lista de IDs de vehículos del catálogo separados por coma. Devuelve los leads interesados en al menos uno de ellos.
</ParamField>

<ParamField query="search" type="string">
  Texto libre sobre los datos de contacto: nombre, apellido, email y teléfono.
</ParamField>

<ParamField query="created_after" type="string">
  Devuelve solo los leads creados en esta marca de tiempo o después. Cadena de fecha y hora ISO 8601, por ejemplo `2024-01-15T00:00:00Z`.
</ParamField>

<ParamField query="created_before" type="string">
  Devuelve solo los leads creados en esta marca de tiempo o antes. Cadena de fecha y hora ISO 8601, por ejemplo `2024-01-31T23:59:59Z`.
</ParamField>

## Ejemplo de solicitud

```bash cURL
curl 'https://platform-api.deltalead.ai/v1/leads?status=qualified&channel=whatsapp&score_min=70&limit=20' \
  -H "Authorization: Bearer dl_live_YOUR_KEY"
```

### Campos de la respuesta

<ResponseField name="data" type="array">
  Leads que coinciden con los filtros aplicados, del más reciente al más antiguo. Cada elemento tiene la misma forma que devuelve [Obtener lead](/api-reference/leads/get), con una diferencia: acá `interested_vehicles` es un arreglo de IDs del catálogo, sin los datos del vehículo.
</ResponseField>

<ResponseField name="next_cursor" type="string | null">
  Este valor se pasa como parámetro `cursor` para obtener la página siguiente. Es `null` cuando `has_more` es `false`.
</ResponseField>

<ResponseField name="has_more" type="boolean">
  `true` si existen páginas adicionales de resultados.
</ResponseField>

La respuesta no incluye un total: contarlo exige una segunda consulta sobre el mismo filtro en cada página. Para recorrer todo el resultado, se pagina hasta que `has_more` sea `false`.

<Tip>
  Para una sincronización incremental, conviene combinar `created_after` con un cursor almacenado: una primera consulta con `created_after` en la marca de tiempo de la última sincronización y después `next_cursor` hasta agotar el resultado.
</Tip>
