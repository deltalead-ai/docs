La API REST de DeltaLead da acceso programático a leads, conversaciones, agentes de IA y configuración de webhooks. Sirve para construir integraciones a medida, automatizar flujos de trabajo o sincronizar con sistemas que las integraciones nativas no cubren: un DMS propietario, un data warehouse interno o un CRM hecho a medida.

## URL base

Todas las solicitudes a la API se realizan sobre HTTPS contra la siguiente URL base:

```text
https://platform-api.deltalead.ai/v1
```

## Ejemplo rápido

La siguiente solicitud recupera los leads más recientes con `curl`. `YOUR_API_KEY` se reemplaza por la clave de API de la cuenta, que empieza con `dl_live_` o `dl_sandbox_`.

```bash
curl https://platform-api.deltalead.ai/v1/leads \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Formato de las solicitudes

Todos los cuerpos de solicitud y respuesta usan JSON. Al enviar datos en solicitudes `POST` o `PATCH`, hay que incluir la cabecera `Content-Type: application/json` para que la API pueda interpretar el cuerpo correctamente.

```bash
curl -X POST https://platform-api.deltalead.ai/v1/leads \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"contact": {"first_name": "Martín", "last_name": "Sosa", "phone": "+5491122334455"}}'
```

Los datos de la persona viajan siempre dentro del objeto anidado `contact`. Se requiere al menos uno de `first_name` o `last_name`, y al menos uno de `email` o `phone`.

Las solicitudes `GET` y `DELETE` no requieren la cabecera `Content-Type`.

## Límites de tasa

El límite se aplica por clave de API: **5 solicitudes por segundo sostenidas**, con una **ráfaga de hasta 10**. Al superarlo, la API devuelve una respuesta `429 Too Many Requests` con la cabecera `Retry-After`, que indica cuántos segundos esperar antes de reintentar.

`Retry-After` es la única cabecera de recuperación que emite la API; no hay cabeceras de consumo restante. La [referencia de errores](/api-reference/errors) detalla el manejo completo de `429` y la estrategia de backoff exponencial.
