<Note>
  The REST API is in early access and is enabled per account on request. API keys are not yet issued from the dashboard. To request access, contact your account executive.
</Note>

Fetch the full detail of a lead by its identifier. Use this endpoint to display a lead inside your own tooling, sync a record to an external CRM, or read the latest state before taking an action.

## Endpoint

```text
GET https://platform-api.deltalead.ai/v1/leads/{id}
```

## Path Parameters

<ParamField path="id" type="string" required>
  The unique identifier of the lead. Lead IDs are prefixed with `lead_`, e.g. `lead_abc123`. You can obtain them from [List Leads](/en/api-reference/leads/list) or from webhook payloads.
</ParamField>

## Example Request

```bash cURL
curl https://platform-api.deltalead.ai/v1/leads/lead_abc123 \
  -H "Authorization: Bearer dl_live_YOUR_KEY"
```

### Response Fields

<ResponseField name="id" type="string">
  Unique identifier for the lead, prefixed with `lead_`.
</ResponseField>

<ResponseField name="organization_id" type="string">
  Identifier of the organization (dealership) that owns the lead.
</ResponseField>

<ResponseField name="status" type="string">
  Current status within the pipeline. One of `new`, `contacted`, `qualified`, `appointment`, `proposal`, `incubating`, `won`, `lost`.
</ResponseField>

<ResponseField name="source" type="string | null">
  Origin label reported by the system that generated the lead, e.g. `landing-page`. It is free text and does not replace `channels`.
</ResponseField>

<ResponseField name="score" type="integer">
  Qualification score, an integer from `0` to `100`.
</ResponseField>

<ResponseField name="contact" type="object">
  Contact details for the person. Name, email, and phone live here, never at the root of the lead.
</ResponseField>

<ResponseField name="contact.first_name" type="string | null">
  Given name.
</ResponseField>

<ResponseField name="contact.last_name" type="string | null">
  Family name.
</ResponseField>

<ResponseField name="contact.email" type="string | null">
  Email address. `null` if unknown.
</ResponseField>

<ResponseField name="contact.phone" type="string | null">
  Phone number, normally in E.164 format. `null` if unknown.
</ResponseField>

<ResponseField name="contact.display_name" type="string">
  Display name, composed from `first_name` and `last_name` when none was provided.
</ResponseField>

<ResponseField name="channels" type="array of string">
  Channels the lead has communicated through. It is an array because a lead accumulates them. Possible values: `whatsapp`, `mercadolibre`, `typeform`, `custom`, `manual`, `email`.
</ResponseField>

<ResponseField name="interested_vehicles" type="array of object">
  Catalogue vehicles the lead asked about. In the detail response they come enriched with the vehicle data; on writes and in [List Leads](/en/api-reference/leads/list) they are plain IDs.
</ResponseField>

<ResponseField name="interested_vehicles[].id" type="string">
  Identifier of the vehicle in the catalogue.
</ResponseField>

<ResponseField name="interested_vehicles[].name" type="string">
  Name of the vehicle as it appears in the catalogue.
</ResponseField>

<ResponseField name="tags" type="array of string">
  Tags applied to the lead by your team.
</ResponseField>

<ResponseField name="assigned_to" type="string | null">
  ID of the salesperson the lead is assigned to. `null` if unassigned.
</ResponseField>

<ResponseField name="notes" type="array of object">
  Notes on the lead, oldest first. Always an array of objects.
</ResponseField>

<ResponseField name="notes[].id" type="string">
  Identifier of the note.
</ResponseField>

<ResponseField name="notes[].body" type="string">
  Note text.
</ResponseField>

<ResponseField name="notes[].author_id" type="string | null">
  ID of the person who wrote the note. `null` when an integration generated it.
</ResponseField>

<ResponseField name="notes[].source" type="string">
  Origin of the note: `manual` when a person wrote it or it arrived through the API, or the channel that produced it.
</ResponseField>

<ResponseField name="notes[].created_at" type="string">
  ISO 8601 timestamp of when the note was created.
</ResponseField>

<ResponseField name="notes[].updated_at" type="string">
  ISO 8601 timestamp of the last edit to the note.
</ResponseField>

<ResponseField name="ai_summary" type="string | null">
  AI Summary of the conversation. `null` while `ai_summary_status` is anything other than `completed`.
</ResponseField>

<ResponseField name="ai_summary_status" type="string">
  State of the AI Summary. One of `not_requested`, `pending`, `completed`, `failed`.
</ResponseField>

<ResponseField name="last_activity_at" type="string">
  ISO 8601 timestamp of the last interaction recorded for this lead.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the lead was created.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 timestamp of the most recent change to any field on the lead.
</ResponseField>

## Errors

<Accordion title="404 — Lead not found">
  Returned when no lead with that `id` exists in your organization.

  ```json 404 Not Found
  {
    "status": "error",
    "detail": "lead_not_found"
  }
  ```

  An ID belonging to another organization also returns `404`. Branch on the `detail` identifier, never on the text — see [Errors](/en/api-reference/errors).
</Accordion>
