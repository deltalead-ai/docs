<Note>
  The REST API is in early access and is enabled per account on request. API keys are not yet issued from the dashboard. To request access, contact your account executive.
</Note>

Return your organization's leads in a cursor-paginated response. The query parameters narrow the result by status, channel, score range, catalogue vehicle, free text, or creation date, so you can surface exactly the pipeline segment your integration needs.

## Endpoint

```text
GET https://platform-api.deltalead.ai/v1/leads
```

## Query Parameters

<ParamField query="limit" type="integer" default="20">
  Maximum number of leads per page. An integer between `1` and `100`.
</ParamField>

<ParamField query="cursor" type="string">
  Pagination cursor returned as `next_cursor` by the previous response. Omit it to start from the first page. The value is opaque: do not parse or construct it.
</ParamField>

<ParamField query="status" type="string">
  Filter by the lead's current status. Accepted values: `new`, `contacted`, `qualified`, `appointment`, `proposal`, `incubating`, `won`, `lost`.
</ParamField>

<ParamField query="channel" type="string">
  Return the leads that have accumulated this channel. Accepted values: `whatsapp`, `mercadolibre`, `typeform`, `custom`, `manual`, `email`.
</ParamField>

<ParamField query="score_min" type="integer">
  Return only leads with a score greater than or equal to this value. Range: `0`–`100`.
</ParamField>

<ParamField query="score_max" type="integer">
  Return only leads with a score less than or equal to this value. Range: `0`–`100`.
</ParamField>

<ParamField query="interested_vehicle_ids" type="string">
  Comma-separated list of catalogue vehicle IDs. Returns the leads interested in at least one of them.
</ParamField>

<ParamField query="search" type="string">
  Free text over the contact details: first name, last name, email, and phone.
</ParamField>

<ParamField query="created_after" type="string">
  Return only leads created on or after this timestamp. An ISO 8601 date-time string, e.g. `2024-01-15T00:00:00Z`.
</ParamField>

<ParamField query="created_before" type="string">
  Return only leads created on or before this timestamp. An ISO 8601 date-time string, e.g. `2024-01-31T23:59:59Z`.
</ParamField>

## Example Request

```bash cURL
curl 'https://platform-api.deltalead.ai/v1/leads?status=qualified&channel=whatsapp&score_min=70&limit=20' \
  -H "Authorization: Bearer dl_live_YOUR_KEY"
```

### Response Fields

<ResponseField name="data" type="array">
  Leads matching the applied filters, most recent first. Each element has the same shape [Get Lead](/en/api-reference/leads/get) returns, with one difference: here `interested_vehicles` is an array of catalogue IDs, without the vehicle data.
</ResponseField>

<ResponseField name="next_cursor" type="string | null">
  Pass this value as the `cursor` parameter to fetch the next page. `null` when `has_more` is `false`.
</ResponseField>

<ResponseField name="has_more" type="boolean">
  `true` if additional pages of results exist.
</ResponseField>

The response carries no total: counting one requires a second query over the same filter on every page. To walk the whole result, paginate until `has_more` is `false`.

<Tip>
  For an incremental sync, combine `created_after` with a stored cursor: fetch once with `created_after` set to your last sync timestamp, then follow `next_cursor` until the result is exhausted.
</Tip>
