description: "Selectively update a lead — status, contact, tags, assignment, vehicles, channels, source, score, and internal notes — leaving everything else untouched."
---

<Note>
  The REST API is in early access and is enabled per account on request. API keys are not yet issued from the dashboard. To request access, contact your account executive.
</Note>

Update one or more fields on an existing lead without overwriting the whole record: advance the lead through the pipeline, assign it to a salesperson, correct the contact details, or change the vehicles of interest. The semantics are PATCH, so you only send the fields that change.

## Endpoint

```text
PATCH https://platform-api.deltalead.ai/v1/leads/{id}
```

## Path Parameters

<ParamField path="id" type="string" required>
  The unique identifier of the lead to update, e.g. `lead_abc123`.
</ParamField>

## Request Body

All fields are optional, and only the ones present in the request are modified. Fields outside this list are silently ignored: the response is still `200`, but the value is not stored.

<ParamField body="status" type="string">
  New status for the lead. Closed enum: `new`, `contacted`, `qualified`, `appointment`, `proposal`, `incubating`, `won`, `lost`.
</ParamField>

<ParamField body="contact" type="object">
  Contact details: `first_name`, `last_name`, `email`, `phone`, `display_name`. They are merged field by field, so anything not sent inside `contact` stays as it was.
</ParamField>

<ParamField body="tags" type="array of string">
  Tags on the lead. The array replaces the previous one entirely.
</ParamField>

<ParamField body="assigned_to" type="string | null">
  ID of the salesperson responsible for the lead. Pass `null` to leave it unassigned.
</ParamField>

<ParamField body="interested_vehicles" type="array of string">
  Catalogue vehicle IDs. The array replaces the previous one entirely. Writes take plain IDs, even though the lead detail returns them enriched.
</ParamField>

<ParamField body="channels" type="array of string">
  Channels associated with the lead: `whatsapp`, `mercadolibre`, `typeform`, `custom`, `manual`, `email`. The array replaces the previous one entirely.
</ParamField>

<ParamField body="source" type="string">
  Origin label for the lead, e.g. `landing-page`.
</ParamField>

<ParamField body="score" type="integer">
  Qualification score, an integer from `0` to `100`. A value written through the API replaces whatever the AI computed.
</ParamField>

<ParamField body="internal_notes" type="string">
  Your team's internal notes on the lead. This is a write-only field: it does not appear in the lead returned by this endpoint or by [Get Lead](/en/api-reference/leads/get).
</ParamField>

## Example Request

Book an appointment, assign the salesperson, and update the vehicles of interest:

```bash cURL
curl -X PATCH https://platform-api.deltalead.ai/v1/leads/lead_abc123 \
  -H "Authorization: Bearer dl_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "status": "appointment",
    "assigned_to": "user_xyz789",
    "tags": ["financiacion", "test-drive"],
    "interested_vehicles": ["veh_9f2c41", "veh_71ba08"]
  }'
```

<Note>
  Only the fields present in the body are modified; omitted fields stay exactly as they were. Arrays are replaced whole rather than appended to: to add one tag, send the complete list. To clear an optional field such as `assigned_to`, pass it explicitly as `null`.
</Note>
