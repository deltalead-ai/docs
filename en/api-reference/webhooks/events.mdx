This page is the definitive reference for every webhook event DeltaLead can deliver to your endpoint. Events are grouped by domain: lead lifecycle, conversation activity, appointments, and escalations to a human. For each event you will find the trigger condition and a full example payload so you know exactly what to expect in your handler.

<Note>
  Subscribe only to the events your integration actually needs. Filtering out irrelevant event types reduces unnecessary POST requests to your server and keeps your handler logic focused.
</Note>

## Lead Lifecycle Events

<Accordion title="lead.created — New lead enters DeltaLead">
  Fired the moment a new lead arrives in DeltaLead from any connected channel — WhatsApp, MercadoLibre, Typeform, the Custom Webhook, email, or manual entry. At creation the lead's score is `0`; qualification happens asynchronously and triggers `lead.qualified` once complete.

  ```json Example payload
  {
    "event": "lead.created",
    "timestamp": "2024-11-07T10:00:00Z",
    "organization_id": "org_xyz789",
    "data": {
      "id": "lead_abc123",
      "status": "new",
      "score": 0,
      "source": "landing-page",
      "contact": {
        "first_name": "Carlos",
        "last_name": "Rodríguez",
        "email": "carlos.rodriguez@example.com",
        "phone": "+5491144441234"
      },
      "channels": ["whatsapp"],
      "interested_vehicles": ["veh_9f3c21"],
      "created_at": "2024-11-07T10:00:00Z"
    }
  }
  ```
</Accordion>

<Accordion title="lead.qualified — AI completes lead qualification">
  Fired when the AI agent has finished its qualification conversation and assigned a purchase-intent score. The `score` field ranges from `0` to `100`. The summary produced by qualification is reflected in `ai_summary_status`, which turns `completed` once the AI Summary is available on the lead.

  ```json Example payload
  {
    "event": "lead.qualified",
    "timestamp": "2024-11-07T10:07:30Z",
    "organization_id": "org_xyz789",
    "data": {
      "id": "lead_abc123",
      "status": "qualified",
      "score": 87,
      "contact": {
        "first_name": "Carlos",
        "last_name": "Rodríguez",
        "email": "carlos.rodriguez@example.com",
        "phone": "+5491144441234"
      },
      "channels": ["whatsapp"],
      "interested_vehicles": ["veh_9f3c21"],
      "ai_summary_status": "completed"
    }
  }
  ```
</Accordion>

<Accordion title="lead.updated — Lead status, score, or assignment changes">
  Fired whenever a lead record is modified after creation. Common triggers include a manual status change by a seller, a score revision after a follow-up conversation, or an update to the vehicles of interest.

  ```json Example payload
  {
    "event": "lead.updated",
    "timestamp": "2024-11-07T11:00:00Z",
    "organization_id": "org_xyz789",
    "data": {
      "id": "lead_abc123",
      "status": "contacted",
      "score": 91,
      "contact": {
        "first_name": "Carlos",
        "last_name": "Rodríguez",
        "email": "carlos.rodriguez@example.com",
        "phone": "+5491144441234"
      },
      "channels": ["whatsapp"],
      "interested_vehicles": ["veh_9f3c21"],
      "updated_at": "2024-11-07T11:00:00Z"
    }
  }
  ```
</Accordion>

<Accordion title="lead.assigned — Lead assigned to a seller">
  Fired when a qualified lead is assigned to a specific member of your sales team, either automatically by DeltaLead's routing rules or manually by a manager. Use this event to notify the assigned seller via your own systems.

  ```json Example payload
  {
    "event": "lead.assigned",
    "timestamp": "2024-11-07T11:05:00Z",
    "organization_id": "org_xyz789",
  ```

## Conversation Events

<Accordion title="conversation.started — New conversation begins">
  Fired when a lead initiates a new conversation on any channel. A single lead can have multiple conversations over time; each one triggers its own `conversation.started` event.

  ```json Example payload
  {
    "event": "conversation.started",
    "timestamp": "2024-11-07T10:00:05Z",
    "organization_id": "org_xyz789",
    "data": {
      "id": "conv_111aaa",
      "lead_id": "lead_abc123",
      "status": "open",
      "assignee": null,
      "unread_count": 1,
      "last_inbound_at": "2024-11-07T10:00:05Z"
    }
  }
  ```
</Accordion>

<Accordion title="message.received — Inbound message arrives">
  Fired each time a new inbound message is received from the lead during an active conversation. Subscribe to this event to mirror conversation history in your own CRM or data warehouse in real time. The message text travels in `body`; attachments and audio transcription, when present, travel in `media`.

  ```json Example payload
  {
    "event": "message.received",
    "timestamp": "2024-11-07T10:01:20Z",
    "organization_id": "org_xyz789",
    "data": {
      "conversation_id": "conv_111aaa",
      "lead_id": "lead_abc123",
      "message": {
        "id": "msg_999zzz",
        "direction": "inbound",
        "body": "¿Tienen la Hilux SRX en stock?",
        "type": "text",
        "media": [],
        "received_at": "2024-11-07T10:01:20Z"
      }
    }
  }
  ```
</Accordion>

## Appointment Events

<Accordion title="appointment.scheduled — AI books a test drive or showroom visit">
  Fired when an AI agent successfully schedules an appointment with a lead — typically a test drive or showroom visit. Use this event to add the appointment to your calendar system, notify the responsible seller, or prepare the vehicle.

  ```json Example payload
  {
    "event": "appointment.scheduled",
    "timestamp": "2024-11-07T10:12:00Z",
    "organization_id": "org_xyz789",
    "data": {
      "lead_id": "lead_abc123",
      "conversation_id": "conv_111aaa",
      "appointment_type": "test_drive",
      "scheduled_at": "2024-11-09T11:00:00Z"
    }
  }
  ```
</Accordion>

## Escalation Events

<Accordion title="escalation.created — AI transfers conversation to a human">
  Fired when an AI agent determines that a conversation requires human intervention and escalates it. This occurs when one of the agent's configured business rules is met — for example, a lead asking to negotiate pricing or inquire about financing terms. The receiving seller gets full conversation context.

  ```json Example payload
  {
    "event": "escalation.created",
    "timestamp": "2024-11-07T10:15:00Z",
    "organization_id": "org_xyz789",
    "data": {
      "conversation_id": "conv_111aaa",
      "lead_id": "lead_abc123",
      "ai_agent_id": "agent_abc123",
      "ai_agent_name": "Martín de Ventas",
      "reason": "financing",
      "assigned_to": {
        "id": "user_seller001",
        "name": "Laura Méndez",
        "email": "laura.mendez@concesionaria.com"
      },
      "escalated_at": "2024-11-07T10:15:00Z"
    }
  }
  ```
</Accordion>
