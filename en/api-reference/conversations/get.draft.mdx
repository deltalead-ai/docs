<Note>
  The REST API is in early access and is enabled per account on request. API keys are not yet issued from the dashboard. To request access, contact your account executive.
</Note>

Fetch a single conversation by its identifier, with the complete message thread. Use it to embed conversation history inside your CRM records, audit the AI agent's replies, or show a seller the full context before they take over.

The conversation references the lead through `lead_id`. Contact details do not travel here: fetch them from [Get lead](/en/api-reference/leads/get), where they live inside the `contact` object.

## Endpoint

```text
GET https://platform-api.deltalead.ai/v1/conversations/{id}
```

## Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the conversation to retrieve, e.g. `conv_xyz789`. Conversation IDs come from the [List conversations](/en/api-reference/conversations/list) endpoint or from webhook payloads.
</ParamField>

## Example request

```bash cURL
curl https://platform-api.deltalead.ai/v1/conversations/conv_xyz789 \
  -H "Authorization: Bearer dl_live_..."
```

### Response fields

<ResponseField name="id" type="string">
  Unique identifier of the conversation, prefixed with `conv_`.
</ResponseField>

<ResponseField name="organization_id" type="string">
  ID of the organization the conversation belongs to.
</ResponseField>

<ResponseField name="lead_id" type="string">
  ID of the lead the conversation belongs to.
</ResponseField>

<ResponseField name="status" type="string">
  Current status: `open` (the AI agent is handling it), `handed_off` (handed to a person), or `resolved` (closed).
</ResponseField>

<ResponseField name="assignee" type="string | null">
  ID of the person in charge of the conversation. `null` while the AI agent is handling it.
</ResponseField>

<ResponseField name="unread_count" type="integer">
  Number of unread inbound messages in the unified inbox.
</ResponseField>

<ResponseField name="last_inbound_at" type="string | null">
  ISO 8601 timestamp of the last message sent by the lead.
</ResponseField>

<ResponseField name="last_message_at" type="string">
  ISO 8601 timestamp of the most recent message, in either direction.
</ResponseField>

<ResponseField name="messages" type="array">
  Ordered array of messages, from oldest to newest.

  <Expandable title="Message object fields">
    <ResponseField name="id" type="string">
      Unique identifier of the message, prefixed with `msg_`.
    </ResponseField>
    <ResponseField name="conversation_id" type="string">
      ID of the conversation this message belongs to.
    </ResponseField>
    <ResponseField name="direction" type="string">
      `inbound` for messages sent by the lead; `outbound` for messages sent by DeltaLead, whether by the AI agent or by a person.
    </ResponseField>
    <ResponseField name="body" type="string">
      Text body of the message. It is empty when the message carries only attachments — the content is then in `media`.
    </ResponseField>
    <ResponseField name="type" type="string">
      Message type. One of `text`, `audio`, `image`, `document`.
    </ResponseField>
    <ResponseField name="media" type="array">
      Files attached to the message. An empty array on text messages.

      <Expandable title="Media object fields">
        <ResponseField name="id" type="string">
          Unique identifier of the file.
        </ResponseField>
        <ResponseField name="type" type="string">
          File type. One of `audio`, `image`, `document`.
        </ResponseField>
        <ResponseField name="url" type="string">
          Download URL for the file. It requires the same API key as the rest of the API.
        </ResponseField>
        <ResponseField name="mime_type" type="string">
          MIME type of the file, e.g. `audio/ogg`.
        </ResponseField>
        <ResponseField name="transcription" type="string | null">
          Transcription of the audio, when the file is of type `audio` and the transcription is ready. `null` otherwise. Transcriptions always travel here, never in a separate conversation field.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="sender" type="string">
      Who originated the message. One of `lead`, `ai_agent`, `human`.
    </ResponseField>
    <ResponseField name="ai_agent_id" type="string | null">
      ID of the AI agent that generated the message. `null` when `sender` is not `ai_agent`.
    </ResponseField>
    <ResponseField name="ai_agent_name" type="string | null">
      Name of the AI agent at the time the message was sent. It is stored alongside the message so history does not change if the agent is renamed later.
    </ResponseField>
    <ResponseField name="status" type="string">
      Delivery status of the message. One of `queued`, `sent`, `delivered`, `failed`.
    </ResponseField>
    <ResponseField name="error_code" type="string | null">
      Identifier of the failure reason, in `snake_case`. Only populated when `status` is `failed`.
    </ResponseField>
    <ResponseField name="received_at" type="string | null">
      ISO 8601 timestamp of when the channel delivered the message to DeltaLead. `null` on outbound messages.
    </ResponseField>
    <ResponseField name="created_at" type="string">
      ISO 8601 timestamp of message creation.
    </ResponseField>
    <ResponseField name="updated_at" type="string">
      ISO 8601 timestamp of the last change to the message, such as moving from `sent` to `delivered` or a transcription completing.
    </ResponseField>
  </Expandable>
</ResponseField>
