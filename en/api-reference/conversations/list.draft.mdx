<Note>
  The REST API is in early access and is enabled per account on request. API keys are not yet issued from the dashboard. To request access, contact your account executive.
</Note>

Returns the conversations in your organization, most recently active first. Each conversation belongs to a lead and groups the entire exchange with that person. Filter by `lead_id` to pull the threads of a specific contact, or by `status` to monitor open threads and the ones a seller has already taken over.

Objects in this list do not include the `messages` array. For the full thread, use [Get conversation](/en/api-reference/conversations/get).

## Endpoint

```text
GET https://platform-api.deltalead.ai/v1/conversations
```

## Query parameters

<ParamField query="limit" type="integer" default="20">
  Maximum number of conversations to return per page. Accepts values between `1` and `100`.
</ParamField>

<ParamField query="cursor" type="string">
  Opaque pagination cursor taken from the `next_cursor` field of the previous response. Omit it to start from the first page. Do not parse or construct the cursor yourself.
</ParamField>

<ParamField query="lead_id" type="string">
  Restricts conversations to a single lead. Pass a lead ID such as `lead_abc123`.
</ParamField>

<ParamField query="status" type="string">
  Filter by conversation status. Accepted values: `open`, `handed_off`, `resolved`.
</ParamField>

<ParamField query="assignee" type="string">
  Restricts conversations to those assigned to a specific person, by user ID.
</ParamField>

## Example request

```bash cURL
curl 'https://platform-api.deltalead.ai/v1/conversations?lead_id=lead_abc123&status=open' \
  -H "Authorization: Bearer dl_live_..."
```

## Response

A successful request returns `200 OK` with a `data` array of conversations and the pagination fields `next_cursor` and `has_more` at the root level.

```json 200 OK
{
  "data": [
    {
      "id": "conv_xyz789",
      "organization_id": "org_xyz789",
      "lead_id": "lead_abc123",
      "status": "open",
      "assignee": null,
      "unread_count": 2,
      "last_inbound_at": "2024-03-11T09:04:58Z",
      "last_message_at": "2024-03-11T09:05:33Z"
    },
    {
      "id": "conv_mno321",
      "organization_id": "org_xyz789",
      "lead_id": "lead_def456",
      "status": "handed_off",
      "assignee": "user_xyz789",
      "unread_count": 0,

      "last_message_at": "2024-03-09T11:12:10Z"

  "has_more": false

```

### Response fields

<ResponseField name="data" type="array">
  Array of conversations matching the applied filters.
</ResponseField>

<ResponseField name="data[].id" type="string">
  Unique identifier of the conversation, prefixed with `conv_`.
</ResponseField>

<ResponseField name="data[].organization_id" type="string">
  ID of the organization the conversation belongs to.
</ResponseField>

<ResponseField name="data[].lead_id" type="string">
  ID of the lead the conversation belongs to. Contact details come from [Get lead](/en/api-reference/leads/get), where they live inside `contact`.
</ResponseField>

<ResponseField name="data[].status" type="string">
  Current status of the conversation. One of:
  - `open` — the AI agent is handling it
  - `handed_off` — handed to a person, who is answering
  - `resolved` — closed, no further messages expected
</ResponseField>

<ResponseField name="data[].assignee" type="string | null">
  ID of the person in charge of the conversation. `null` while the AI agent is handling it.
</ResponseField>

<ResponseField name="data[].unread_count" type="integer">
  Number of unread inbound messages in the unified inbox.
</ResponseField>

<ResponseField name="data[].last_inbound_at" type="string | null">
  ISO 8601 timestamp of the last message sent by the lead. `null` if the lead has not replied yet.
</ResponseField>

<ResponseField name="data[].last_message_at" type="string">
  ISO 8601 timestamp of the most recent message in the conversation, in either direction.
</ResponseField>

<ResponseField name="next_cursor" type="string | null">
  Pass this value as `cursor` to fetch the next page. `null` when `has_more` is `false`.
</ResponseField>

<ResponseField name="has_more" type="boolean">
  `true` if additional pages exist.
</ResponseField>
