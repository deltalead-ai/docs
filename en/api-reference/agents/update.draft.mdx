---
title: "PATCH /v1/agents/{id} — Update an AI Agent"
sidebarTitle: "Update Agent"
description: "PATCH /v1/agents/{id} partially updates an AI agent's language, tone, message length, and business and lead qualification rules."
---

<Note>
  The REST API is in early access and is enabled per account on request. API keys are not yet issued from the dashboard. To request access, contact your account executive.
</Note>

Update the configuration of an existing AI agent without replacing the entire record. Send only the fields you want to change — DeltaLead applies a partial update and leaves every unspecified field untouched. Use it to tune how the AI agent converses over time, localize it for a new market, or add a commercial rule it did not have before.

## Endpoint

```http
PATCH https://platform-api.deltalead.ai/v1/agents/{id}
```

## Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the AI agent to update, e.g. `agent_abc123`.
</ParamField>

## Request body

All fields are optional. Include only the ones you want to change.

<ParamField body="language" type="string">
  Locale key the AI agent converses in. Accepted values: `es_AR`, `es_MX`, `es_CR`, `es_CO`, `pt_BR`, `en_US`.
</ParamField>

<ParamField body="tone_of_voice" type="string">
  Conversational tone. Accepted values: `formal`, `friendly`, `professional`.
</ParamField>

<ParamField body="text_size" type="string">
  Length of the messages the AI agent writes. Accepted values: `short`, `medium`, `long`.
</ParamField>

<ParamField body="business_rules" type="string">
  Business rules for the AI agent: discount limits, financing terms, delivery times. Replaces the full text — it is not appended to the existing one.
</ParamField>

<ParamField body="lead_qualification_rules" type="string">
  Lead qualification rules for the AI agent. Replaces the full text — it is not appended to the existing one.
</ParamField>

<Note>
  `name`, `type`, and `assigned_phone_value` are not editable through the API: they are set when the AI agent is created and when a number is assigned to it from the dashboard. `version`, `created_at`, and `updated_at` are maintained by the platform.
</Note>

## Example request

The following request localizes the AI agent for Mexico, switches it to a professional tone, and shortens its messages.

```bash cURL
curl -X PATCH https://platform-api.deltalead.ai/v1/agents/agent_abc123 \
  -H "Authorization: Bearer dl_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "language": "es_MX",
    "tone_of_voice": "professional",
    "text_size": "short"
  }'
```

## Response

A successful request returns `200 OK` with the full updated AI agent object and an incremented `version` field.

```json 200 OK
{
  "id": "agent_abc123",
  "organization_id": "org_xyz789",
  "name": "Martín de Ventas",
  "type": "sales",
  "language": "es_MX",
  "tone_of_voice": "professional",
  "text_size": "short",
  "assigned_phone_value": "+5491123456789",
  "version": 8,
  "business_rules": "No ofrecer descuentos mayores al 5% sin aprobación. Financiación hasta 60 cuotas.",
  "lead_qualification_rules": "Calificar cuando el lead confirma modelo, presupuesto y plazo de compra.",
  "created_at": "2024-01-15T10:00:00Z",
  "updated_at": "2024-11-07T17:45:00Z"
}
```

## Error responses

When the ID does not match any AI agent in your organization, the API returns `404 Not Found`.

```json 404 Not Found
{
  "status": "error",
  "detail": "agent_not_found"
}
```

<Warning>
  Changes apply to every message the AI agent generates from that point on, including in conversations that are already open. A change to `language` or `business_rules` during business hours shows up in the very next reply, so check which conversations are active before making it.
</Warning>
