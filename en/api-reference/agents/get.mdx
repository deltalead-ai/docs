<Note>
  The REST API is in early access and is enabled per account on request. API keys are not yet issued from the dashboard. To request access, contact your account executive.
</Note>

Fetch the complete configuration of a single AI agent by its ID: the language it converses in, its tone, the length of the messages it writes, the number it writes from, and the business and qualification rules it follows.

An AI agent is not a seller. Sellers are people at the dealership and receive handed-off conversations; AI agents are the ones that converse automatically, and they are the resource this section describes.

## Endpoint

```http
GET https://platform-api.deltalead.ai/v1/agents/{id}
```

## Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the AI agent to retrieve, e.g. `agent_abc123`.
</ParamField>

## Example request

```bash cURL
curl https://platform-api.deltalead.ai/v1/agents/agent_abc123 \
  -H "Authorization: Bearer dl_live_..."
```

## Response

A successful request returns `200 OK` with the full AI agent object.

```json 200 OK
{
  "id": "agent_abc123",
  "organization_id": "org_xyz789",
  "name": "Martín de Ventas",
  "type": "sales",
  "language": "es_AR",
  "tone_of_voice": "friendly",
  "text_size": "short",
  "assigned_phone_value": "+5491123456789",
  "version": 7,
  "business_rules": "No ofrecer descuentos mayores al 5% sin aprobación. Financiación hasta 60 cuotas.",
  "lead_qualification_rules": "Calificar cuando el lead confirma modelo, presupuesto y plazo de compra.",
  "created_at": "2024-01-15T10:00:00Z",
  "updated_at": "2024-10-01T08:30:00Z"
}
```

### Response fields

<ResponseField name="id" type="string">
  Unique identifier of the AI agent.
</ResponseField>

<ResponseField name="organization_id" type="string">
  ID of the organization the AI agent belongs to.
</ResponseField>

<ResponseField name="name" type="string">
  Name the AI agent introduces itself with to the lead.
</ResponseField>

<ResponseField name="type" type="string">
  Agent type, e.g. `sales` or `support`. It determines the playbook the agent follows and is set during onboarding.
</ResponseField>

<ResponseField name="language" type="string">
  Locale key the AI agent converses in: `es_AR`, `es_MX`, `es_CR`, `es_CO`, `pt_BR`, or `en_US`.
</ResponseField>

<ResponseField name="tone_of_voice" type="string">
  Conversational tone: `formal`, `friendly`, or `professional`.
</ResponseField>

<ResponseField name="text_size" type="string">
  Length of the messages the AI agent writes: `short`, `medium`, or `long`.
</ResponseField>

<ResponseField name="assigned_phone_value" type="string | null">
  E.164 phone number the AI agent converses from. `null` if no number is assigned yet.
</ResponseField>

<ResponseField name="version" type="integer">
  Version number of the configuration. It increments on every update.
</ResponseField>

<ResponseField name="business_rules" type="string">
  Business rules the AI agent answers from: discount limits, financing terms, delivery times. This is the text edited through [Update agent](/en/api-reference/agents/update).
</ResponseField>

<ResponseField name="lead_qualification_rules" type="string">
  Rules that define when the AI agent considers a lead qualified and what information it must gather first.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the AI agent was created.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 timestamp of the most recent update.
</ResponseField>

## Error responses

When the ID does not match any AI agent in your organization, the API returns `404 Not Found`.

```json 404 Not Found
{
  "status": "error",
  "detail": "agent_not_found"
}
```
