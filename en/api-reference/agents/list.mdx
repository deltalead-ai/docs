<Note>
  The REST API is in early access and is enabled per account on request. API keys are not yet issued from the dashboard. To request access, contact your account executive.
</Note>

Returns a paginated list of the AI agents configured in your organization. Each record carries the full configuration that governs how the agent converses: language, tone, message length, assigned phone number, and the business and qualification rules it works from.

## Endpoint

```http
GET https://platform-api.deltalead.ai/v1/agents
```

## Query parameters

<ParamField query="limit" type="integer" default="20">
  Maximum number of AI agents to return per page. Accepts values between `1` and `100`.
</ParamField>

<ParamField query="cursor" type="string">
  Opaque pagination cursor taken from the `next_cursor` field of the previous response. Omit it to start from the beginning of the list. Do not parse or construct the cursor yourself.
</ParamField>

## Example request

```bash cURL
curl https://platform-api.deltalead.ai/v1/agents \
  -H "Authorization: Bearer dl_live_..."
```

### Response fields

<ResponseField name="data" type="array">
  Array of the AI agents in your organization.

  <Expandable title="AI agent fields">
    <ResponseField name="id" type="string">
      Unique identifier of the AI agent, e.g. `agent_abc123`.
    </ResponseField>
    <ResponseField name="organization_id" type="string">
      ID of the organization the AI agent belongs to.
    </ResponseField>
    <ResponseField name="name" type="string">
      Name the AI agent introduces itself with to the lead.
    </ResponseField>
    <ResponseField name="type" type="string">
      Agent type, e.g. `sales` or `support`. It determines the playbook the agent follows and is set during onboarding.
    </ResponseField>
    <ResponseField name="language" type="string">
      Locale key the AI agent converses in: `es_AR`, `es_MX`, `es_CR`, `es_CO`, `pt_BR`, or `en_US`.
    </ResponseField>
    <ResponseField name="tone_of_voice" type="string">
      Conversational tone: `formal`, `friendly`, or `professional`.
    </ResponseField>
    <ResponseField name="text_size" type="string">
      Length of the messages the AI agent writes: `short`, `medium`, or `long`.
    </ResponseField>
    <ResponseField name="assigned_phone_value" type="string | null">
      E.164 phone number the AI agent converses from. `null` if no number is assigned yet.
    </ResponseField>
    <ResponseField name="version" type="integer">
      Version number of the configuration. It increments on every update to the AI agent.
    </ResponseField>
    <ResponseField name="business_rules" type="string">
      Business rules the AI agent answers from: discount limits, financing terms, delivery times.
    </ResponseField>
    <ResponseField name="lead_qualification_rules" type="string">
      Rules that define when the AI agent considers a lead qualified and what information it must gather first.
    </ResponseField>
    <ResponseField name="created_at" type="string">
      ISO 8601 timestamp of when the AI agent was created.
    </ResponseField>
    <ResponseField name="updated_at" type="string">
      ISO 8601 timestamp of the most recent update.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="next_cursor" type="string | null">
  Pass this value as `cursor` to fetch the next page. `null` when `has_more` is `false`.
</ResponseField>

<ResponseField name="has_more" type="boolean">
  `true` if additional pages exist.
</ResponseField>

<Note>
  This endpoint lists AI agents, not sellers. Sellers are people at the dealership, with a name, nickname, and description, and they are who a handed-off conversation is assigned to through the `assignee` field. The two resources are separate and do not share identifiers.
</Note>
