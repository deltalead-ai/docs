---
title: "PATCH /v1/agents/{id} — actualizar la configuración del agente"
sidebarTitle: "Actualizar agente"
description: "PATCH /v1/agents/{id} actualiza parcialmente el nombre, el idioma, el estado, el tono, los disparadores de derivación o la cadencia de seguimiento de un agente."
---

Permite actualizar la configuración de un agente de IA existente sin reemplazar el registro completo. Se envían únicamente los campos que se quieren cambiar: DeltaLead aplica una actualización parcial y deja intacto todo campo no especificado. Este endpoint sirve para ajustar el comportamiento de un agente con el tiempo, adaptarlo a un mercado nuevo o modificar su cadencia de seguimiento a medida que evoluciona el proceso de ventas.

## Endpoint

```http
PATCH https://api.deltalead.ai/v1/agents/{id}
```

## Parámetros de ruta

<ParamField path="id" type="string" required>
  Identificador único del agente que se quiere actualizar, por ejemplo `agent_abc123`.
</ParamField>

## Cuerpo de la solicitud

Todos los campos del cuerpo de la solicitud son opcionales. Se incluyen solo los campos que se quieren cambiar.

<ParamField body="name" type="string">
  Nuevo nombre visible del agente.
</ParamField>

<ParamField body="status" type="string">
  Nuevo estado del agente. Valores aceptados: `active`, `inactive`.
</ParamField>

<ParamField body="language" type="string">
  Configuración regional de idioma para las conversaciones del agente. Valores aceptados: `es-AR`, `es-MX`, `es-CR`, `es-CO`, `pt-BR`, `en-US`.
</ParamField>

<ParamField body="configuration.tone" type="string">
  Tono conversacional que usa el agente. Valores aceptados: `formal`, `friendly`, `professional`.
</ParamField>

<ParamField body="configuration.handoff_triggers" type="array">
  Reemplaza la lista completa de frases disparadoras de derivación. El agente transfiere la conversación a un vendedor humano cada vez que aparece uno de estos temas.
</ParamField>

<ParamField body="configuration.follow_up_cadence.max_follow_ups" type="integer">
  Cantidad máxima de mensajes de seguimiento que el agente envía por lead.
</ParamField>

<ParamField body="configuration.follow_up_cadence.interval_days" type="integer">
  Cantidad de días de espera entre cada mensaje de seguimiento.
</ParamField>

## Solicitud de ejemplo

La siguiente solicitud adapta el agente a México y ajusta su cadencia de seguimiento a tres mensajes separados por dos días.

```bash cURL
curl -X PATCH https://api.deltalead.ai/v1/agents/agent_abc123 \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "language": "es-MX",
    "configuration": {
      "follow_up_cadence": {
        "max_follow_ups": 3,
        "interval_days": 2
      }
    }
  }'
```

## Respuesta

Una solicitud correcta devuelve el objeto completo del agente ya actualizado.

```json 200 OK
{
  "id": "agent_abc123",
  "organization_id": "org_xyz789",
  "name": "Martín de Ventas",
  "status": "active",
  "language": "es-MX",
  "channels": ["whatsapp", "instagram"],
  "created_at": "2024-01-15T10:00:00Z",
  "updated_at": "2024-11-07T17:45:00Z",
  "configuration": {
    "tone": "friendly",
    "handoff_triggers": [
      "pricing negotiation",
      "financing",
      "trade-in valuation"
    ],
    "allowed_topics": [
      "vehicle availability",
      "pricing",
      "test drive scheduling",
      "financing options"
    ],
    "follow_up_cadence": {
      "max_follow_ups": 3,
      "interval_days": 2,
      "channel": "whatsapp"
    }
  }
}
```

<Warning>
  Cambiar el `language` de un agente **activo** tiene efecto en la **próxima conversación nueva** que inicie el agente. Las conversaciones que ya están en curso continúan en el idioma anterior hasta que se cierran o se derivan a un vendedor humano.
</Warning>
