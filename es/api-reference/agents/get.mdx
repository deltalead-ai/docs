sidebarTitle: "Obtener agente"
description: "GET /v1/agents/{id} — obtiene la configuración completa de un agente de IA, incluidos el tono, los disparadores de derivación y la cadencia de seguimiento."
---

Este endpoint devuelve la configuración completa de un agente de IA a partir de su ID. La respuesta incluye todos los ajustes que gobiernan la forma de comunicarse del agente: su tono, los temas que tiene permitido tratar, las condiciones bajo las cuales deriva la conversación a un vendedor humano y la cadencia que sigue al enviar seguimientos automáticos.

## Endpoint

```http
GET https://api.deltalead.ai/v1/agents/{id}
```

## Parámetros de ruta

<ParamField path="id" type="string" required>
  Identificador único del agente que se quiere recuperar, por ejemplo `agent_abc123`.
</ParamField>

## Solicitud de ejemplo

```bash cURL
curl https://api.deltalead.ai/v1/agents/agent_abc123 \
  -H "X-API-Key: YOUR_API_KEY"
```

## Respuesta

<ResponseField name="id" type="string">
  Identificador único del agente.
</ResponseField>

<ResponseField name="organization_id" type="string">
  ID de la organización a la que pertenece el agente.
</ResponseField>

<ResponseField name="name" type="string">
  Nombre visible del agente.
</ResponseField>

<ResponseField name="status" type="string">
  Estado actual: `active`, `inactive` o `draft`.
</ResponseField>

<ResponseField name="language" type="string">
  Configuración regional de idioma que usa el agente: `es-AR`, `es-MX`, `es-CR`, `es-CO`, `pt-BR` o `en-US`.
</ResponseField>

<ResponseField name="channels" type="array">
  Canales asignados al agente: `whatsapp`, `facebook`, `instagram`, `web`, `email` o `phone`.
</ResponseField>

<ResponseField name="created_at" type="string">
  Marca de tiempo ISO 8601 de la creación del agente.
</ResponseField>

<ResponseField name="updated_at" type="string">
  Marca de tiempo ISO 8601 de la actualización más reciente.
</ResponseField>

<ResponseField name="configuration" type="object">
  Configuración de comportamiento completa del agente.

  <Expandable title="Campos de configuración">
    <ResponseField name="tone" type="string">
      Tono conversacional que usa el agente: `formal`, `friendly` o `professional`.
    </ResponseField>
    <ResponseField name="handoff_triggers" type="array">
      Lista de temas o situaciones que hacen que el agente transfiera la conversación a un vendedor humano, por ejemplo `"pricing negotiation"` o `"financing"`.
    </ResponseField>
    <ResponseField name="allowed_topics" type="array">
      Lista de temas que el agente tiene permitido tratar, por ejemplo `"vehicle availability"` o `"test drive scheduling"`.
    </ResponseField>
    <ResponseField name="follow_up_cadence" type="object">
      Ajustes que controlan los mensajes de seguimiento automáticos.

      <Expandable title="Campos de la cadencia de seguimiento">
        <ResponseField name="max_follow_ups" type="integer">
          Cantidad máxima de mensajes de seguimiento que el agente envía por lead.
        </ResponseField>
        <ResponseField name="interval_days" type="integer">
          Cantidad de días de espera entre cada mensaje de seguimiento.
        </ResponseField>
        <ResponseField name="channel" type="string">
          Canal usado para enviar los mensajes de seguimiento, por ejemplo `whatsapp`.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Respuestas de error

```json 404 Not Found
{
  "error": "not_found",
  "message": "No agent with ID agent_abc123 exists in your organization."
}
```
